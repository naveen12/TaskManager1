# Task Manager

Task Manager is a simple Android application that helps you manage your tasks, alarms, and reminders.

## Features

*   **Scheduleify:** A dashboard that displays your tasks, alarms, and reminders for the selected day.
*   **Tasks:** A list of all your active and completed tasks.
*   **Alarms:** A list of all your active and completed alarms.
*   **Reminders:** A list of all your active and completed reminders.
*   **Themes:** The app supports both light and dark themes.
*   **Export/Import:** You can export and import your data.
